# samsung_iap_flutter_android

[![style: very good analysis][very_good_analysis_badge]][very_good_analysis_link]

The Android implementation of [`samsung_iap_flutter`][app_facing_link], an unofficial Flutter
plugin for Samsung In-App Purchase on Galaxy Store. It bridges Samsung IAP SDK 6.5.2.

## Usage

This package is [endorsed][endorsed_link]. Do not depend on it directly. Add `samsung_iap_flutter`
to your app, and Flutter includes this package automatically.

For setup, the API and the Galaxy build flavor, see the
[`samsung_iap_flutter` README][app_facing_link].
